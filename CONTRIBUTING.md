# Contributing

This repository publishes one master engineering skill. Improve skills/senior-software-engineer/ or its distribution adapters without fragmenting it into separately installed skills.

Before a change, read AGENTS.md, the master SKILL.md and relevant references. Keep relative links valid, synchronize plugin versions, update the changelog and run validation and packaging commands.

Do not add real credentials, personal data or .env files. Do not claim host compatibility or test results without verification. Runtime activation must be tested in the actual host before declaring integration complete.
