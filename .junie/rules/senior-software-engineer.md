# Senior Software Engineer skill routing

For software engineering tasks in this repository, use the master skill at `skills/senior-software-engineer/SKILL.md`. Read only the internal references relevant to the task. Keep one master skill; do not recreate separate Code-First, Harness Engineering or Grill-Me packages.

Apply Code-First by default for clear, bounded implementation, debugging and review tasks. Enter integrated Grill-Me discovery when unresolved assumptions materially affect architecture, business rules, security, data integrity, scope, cost or reversibility. Preserve user changes, permissions, project conventions and security boundaries.
